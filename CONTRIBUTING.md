# Contributing Guide

Thanks for contributing to the PhotonicsPowerLabs program.

## Where to contribute

- **Policy/standards/architecture/program docs:** `PhotonicsPowerLabs`
- **Feature code/bug fixes:** respective sub-repository

## Pull Request Requirements

1. Open PR from a feature branch.
2. Link related issue (if applicable).
3. Keep PR scope focused.
4. Pass all required checks.
5. Obtain required approvals.

## Commit Standards

- Use clear commit messages (Conventional Commits recommended).
- Sign commits where required by repo rules.
- Avoid mixing refactors with functional changes unless necessary.

## Cross-Repo Changes

For changes affecting multiple repos:

1. Open tracking issue in `PhotonicsPowerLabs`
2. Reference all related PRs
3. Document rollout order and compatibility notes
4. Confirm no hidden coupling introduced

## Security

- Never commit secrets or credentials.
- Report vulnerabilities via SECURITY.md process.
- Use dependency updates and pinned versions where possible.
